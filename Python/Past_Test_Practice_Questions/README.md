## 🚀 How Students Can Practice On Their Own (Step-by-Step)

### Step 1: Open the Folder
- Download and extract this folder to your computer.
- Open the extracted folder in **VS Code** (or Python IDLE).

### Step 2: Choose a Question
Every question is organized inside its own folder:
- **`README.md` (or `description.txt`):** The complete problem description, requirements, sample inputs/outputs, and edge cases.
- **`practice.py`:** The starter Python template where you write your code.

### Step 3: Write Your Solution
- Open `practice.py` in VS Code.
- Write your code **inside the function definition(s)** in the top section.
- **Important:** Do NOT change the function name or parameter names!

### Step 4: Run the File (Instant Self-Evaluation!)
- Run the file by clicking the **Run / Play** button in VS Code, or type in terminal:
  ```bash
  python practice.py
  ```
- The built-in **Driver Code** will automatically run your function against multiple test cases (including hidden edge cases) and show you an instant **Pass / Fail** report right in your terminal:
